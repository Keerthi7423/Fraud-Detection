OVERVIEW & BEGINNER'S GUIDE TO DOCKER:
Before we start, let's explain what Docker is in simple terms. 

Imagine you are baking a cake. You have a recipe, the ingredients, and an oven. If you give your friend the same recipe, their cake might taste different because their oven is a different brand or their ingredients are slightly different. 
In programming, "Docker" is a tool that packages your code, your dependencies (ingredients), and the exact environment (the oven) into one single, sealed box called a "Container". This guarantees that if your code works perfectly on your laptop, it will work exactly the same way when deployed to the AWS cloud. 

Amazon Elastic Container Registry (ECR) is simply a giant storage facility in the cloud where we upload these sealed Docker boxes so that AWS can run them later.

STEP 3: Authenticate Docker with your AWS Account
Action: We told Docker to log into your specific AWS account (Account ID: 310297109097 in region eu-north-1).
Command:
`& "C:\Program Files\Amazon\AWSCLIV2\aws.exe" ecr get-login-password --region eu-north-1 | docker login --username AWS --password-stdin 310297109097.dkr.ecr.eu-north-1.amazonaws.com`

STEP 4: Build, Tag, and Push the 4 Services
For each service, we ran three commands:
- `docker build`: Packs your code into the sealed container box.
- `docker tag`: Puts a shipping label on the box with your AWS URL.
- `docker push`: Uploads the box to your AWS ECR storage.

Exact Commands used for all 4 services:

1. Auth Service:
docker build -t fraudguard/auth-service ./services/auth-service
docker tag fraudguard/auth-service:latest 310297109097.dkr.ecr.eu-north-1.amazonaws.com/fraudguard/auth-service:latest
docker push 310297109097.dkr.ecr.eu-north-1.amazonaws.com/fraudguard/auth-service:latest
